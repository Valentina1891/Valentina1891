## 📂 Proyectos destacados

### 🥩 Sistema de gestión de datos para Agrocarnes

Solución desarrollada para reorganizar la información operacional de la empresa, automatizar procesos y mejorar la gestión interna de recursos.

**Principales aportes:**

* Reestructuración de tablas y relaciones de la base de datos.
* Organización y normalización de la información.
* Automatización de procesos internos.
* Implementación de Docker para estandarizar el entorno.
* Mejora de la trazabilidad y disponibilidad de los datos.
* Optimización de la gestión de recursos y del orden interno.

**Tecnologías:** `SQL` `Docker` `Docker Compose` `Bases de datos relacionales` `Automatización`

> El proyecto de portafolio utiliza estructuras recreadas y datos ficticios para proteger la información del cliente.

---

### 🚛 Planificador de operaciones y recursos logísticos

Solución orientada a la gestión de conductores, vehículos, ramplas, turnos, pedidos y operaciones de transporte.

**Principales funcionalidades:**

* Diseño de modelos de datos relacionales en SQL Server.
* Construcción de procedimientos almacenados, vistas y consultas complejas.
* Integración de información desde sistemas internos y APIs REST.
* Gestión de relaciones entre conductores, equipos y operaciones.
* Preparación de datos para reportería y análisis operacional.
* Análisis histórico de viajes, costos y consumo de combustible.

**Tecnologías:** `SQL Server` `Python` `Pandas` `APIs REST` `Node.js`

---

### 📊 Dashboard de resultados académicos

Dashboard desarrollado en Power BI para analizar el desempeño de estudiantes por curso, asignatura, objetivo de aprendizaje y tipo de respuesta.

**Indicadores incluidos:**

* Respuestas correctas.
* Respuestas incorrectas.
* Respuestas omitidas.
* Rendimiento por curso.
* Rendimiento por asignatura.
* Análisis por objetivo de aprendizaje.
* Comparación mediante segmentadores dinámicos.

**Tecnologías:** `Power BI` `DAX` `Power Query` `Excel` `Modelamiento de datos`

---

### 🛣️ Pipeline de análisis de flujo vehicular

Proceso ETL creado para consolidar archivos mensuales de flujo vehicular, estandarizar información e integrar indicadores económicos.

**Principales funcionalidades:**

* Consolidación automática de múltiples archivos.
* Limpieza y transformación de datos.
* Normalización de fechas, categorías y plazas de peaje.
* Integración de valores UF.
* Identificación de registros inconsistentes.
* Generación de totales mensuales, anuales y por punto de cobro.

**Tecnologías:** `Python` `Pandas` `Excel` `ETL` `Power BI`
